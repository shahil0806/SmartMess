# SmartMess Phase 3 Setup

1. Phase 3 ZIP के सभी files (college_logo.jpg सहित) अपने SmartMess folder में copy/replace करें।
2. Terminal में `pip install -r requirements.txt` चलाएँ।
3. `git add .`, commit और `git push origin main` करें।
4. Render का auto-deploy पूरा होने दें।
5. Admin Dashboard में Reports, Menu & Notice और Admin Roles खोलकर test करें।

पुराना MongoDB data सुरक्षित रहेगा। नई collections अपने आप बनेंगी। Main Admin का login पहले वाला `ADMIN_PASSWORD` ही रहेगा।
